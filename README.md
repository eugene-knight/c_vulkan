## Getting Started

Follow these steps to set up the project locally.

### Prerequisites
The following are required:
* ninja
* cmake
* sdl3
* cglm
* Vulkan SDK

### Installation
1. Clone the repository
```sh
git clone https://github.com/eugene-knight/c_vulkan.git
```
2. Build using `ninja`
```sh
cd build/ && ninja
```
3. Run the program
```sh
./untitled
```
